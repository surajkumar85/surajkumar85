## 🚀 Featured Builds

Both of these push past typical CRUD frontend work — real-time media processing and rendering logic living entirely in the browser.

<table>
<tr>
<td width="50%" valign="top">

### 🎞️ Full Fledge Editor
**A complete, browser-native media editor** — no server round-trip for processing. Built on low-level web media primitives to handle encoding, decoding, and real-time playback directly on the client.

**Under the hood:**
- 🔊 **Web Audio API** — real-time audio graph, mixing & effects processing
- 🎥 **WebCodecs API** — hardware-accelerated encode/decode for video & audio
- 🖼️ **Canvas API** — frame-accurate rendering & compositing
- ⚙️ Heavy client-side pipeline (workers / streaming where it counts)
